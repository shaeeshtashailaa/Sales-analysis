# ElectroHub – Project Overview

## Objective

Build an interactive Power BI dashboard for analyzing sales performance and answering the business questions defined in the requirements document.

## Requirement-to-Analysis Mapping

| Requirement | Dashboard Analysis |
|---|---|
| Top/Bottom 5 products | Top and Bottom 5 product visuals by Sales, Profit, and Quantity |
| Sales trends | Time-based sales analysis |
| Sales vs Profit | Profit vs Net Sales visual |
| Period comparison | User-selected period comparison |
| Discount analysis | Average discount by discount category |
| Total orders | Total order KPI |
| Order details | Filterable order-level analysis |
| Sales by city | Sales by City visual |

## Main Measures / Metrics

- Sales
- Net Sales
- Profit
- Quantity Sold
- Discount
- Average Discount
- Number of Orders

## Main Dimensions / Filters

- Product
- Date
- Customer ID
- Promotion Category
- City
- Discount Category

## Portfolio Explanation

This project demonstrates how business requirements can be converted into an interactive BI dashboard. Instead of only presenting raw sales numbers, the dashboard enables users to investigate product performance, profitability, time trends, discounts, orders, and geographic sales distribution.
